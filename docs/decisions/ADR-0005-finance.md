# ADR-0005 - Finans Modeli
- Durum: Müşteri finans kuralları bekleniyor.
- Karar: Yönetimsel finans takibi; resmi muhasebe/e-fatura/fatura kesme aracı değil. Tahmini ve gerçekleşen kayıtlar ayrılır. Para DECIMAL + currency code ile tutulur.
- P0: Nakit/tahakkuk yaklaşımı; P&L gelir/gider tanımı; partial collection/payment; vergi/KDV gösterimi; döviz kuru; runway formülü ve aylık burn varsayımı.
- Bu sorular yanıtlanmadan yalnız UI iskeleti/sentetik demo ilerler; gerçek finans hesap formülü yazılmaz.
