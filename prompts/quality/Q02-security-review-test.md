# Quality Test Q02 - Güvenlik Denetimi Doğrulama

- [ ] Unauthenticated/unauthorized erişim testleri çalıştırılmış.
- [ ] Farklı customer ID ile IDOR testleri yapılmış.
- [ ] Dosya upload/download izinleri ve path/MIME bypass test edilmiş.
- [ ] Finans permission ve export scope test edilmiş.
- [ ] Audit log secret leak ve tamper kontrolü yapılmış.
- [ ] API token scope/expiry/rate limit kontrol edilmiş.
- [ ] Webhook signature/replay/idempotency kontrol edilmiş.
- [ ] Critical/High bulgular açıkça release blocker yapılmış.
- [ ] Testler gerçek müşteri verisi veya üretim sistemi kullanmamış.

Her madde PASS/FAIL/BLOCKED olarak raporlansın. Sadece statik kod okuması ile test geçmiş sayılmaz.
