# Skill: Accessibility and Responsive Quality

Hedef: WCAG 2.2 AA yönünde erişilebilir deneyim; tam uyumluluk iddiası ancak kapsamlı denetimle yapılır.

- Semantic headings/landmarks; visible focus; logical tab order; keyboard support.
- Dialog focus management; form labels/instructions/errors associated.
- Async result/toast announcements where needed.
- Contrast; status not conveyed by color only; reduced motion.
- Tables have meaningful headers; charts have text/table equivalent.
- Responsive desktop/tablet/mobile layouts.
- Kanban drag/drop has keyboard or move-menu alternative.
- Report tested viewport widths, keyboard walkthrough, findings and limitations.
